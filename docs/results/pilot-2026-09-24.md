# Live pilot, 2026-09-24: GLM-5.3 in retail, with and without a flow

The first paired live run of stretto's read-only flow (RFC-001's arm D0): ten retail test-split tasks, drawn at random (seed 7, `pilot/run_pilot.py`), one episode in each arm.

- **Agent:** GLM-5.3 in Claude Code, on Z.ai's GLM Coding Plan endpoint, with τ²-bench's system prompt and no built-in tools.
- **Tools:** τ²-bench's, over MCP, behind `stretto-proxy`.
- **Customer:** GLM-5.3, from τ²-bench's user-simulator prompt.
- **Flow:** compiled goal-free from the 2025 baselines. It takes the likeliest lookup when the tool's probability times the binding's agreement is at least 0.3.
- **Reward:** τ²-bench's database check. The natural-language assertions need an LLM judge and were left out.

## Findings

- **Turns:** 110 LLM turns without the flow and 84 with it, 23.6% fewer. That is 2.6 fewer per episode (95% interval 1.0 to 4.2; paired t = −3.79, p = 0.004), with fewer turns in 9 of 10 pairs (sign test p = 0.02).
- **Tokens:** agent input tokens fell 21.1%, from 724k to 572k.
- **Calls:** the agent made 42 calls of its own, against 69 without the flow. The flow made 26 lookups, and the agent repeated 3 of them.
- **Where the flow acted:** it acted on 9 of the 10 tasks, and there turns fell 26% (104 to 77). On task 17 it never acted, and the episode took one turn more because the simulated customer replied differently.
- **The customer's side:** 54 customer turns in each arm.
- **Outcome:** 8 of 10 passed the database check in each arm. The two failures were the same agent error in both arms. On task 27 the agent processed a return before the exchange it then blocked. On task 64 it chose the wrong variant.
- **Cost:** 236.5 Z.ai credits at the off-peak rate: 128.5 without the flow and 108.0 with it, 16% less.

Ten pairs show that the mechanism works live and give a first effect size. They cannot bound a one-point loss of pass^1, which needs a much larger run.

`pilot-2026-09-24.json` holds the per-task numbers. The episodes themselves (conversations, event streams, proxy logs, flow answers) are not published.
