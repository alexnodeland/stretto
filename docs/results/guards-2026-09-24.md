# Policy guards against recorded trajectories

Every write in every episode is checked against what came before it, as `stretto-proxy --guards` checks it, and sorted by whether the tool accepted it. A failure on a write the tool refused agrees with the tool. A failure on an accepted write of a successful episode is a false alarm, or a policy the episode broke and passed anyway (τ²-bench grades the database, not every rule). Only enforced rules refuse a write; the others are logged.
